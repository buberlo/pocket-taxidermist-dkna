# Pocket Taxidermist

> Turn abandoned apps into stuffed animals that flinch when you reopen them.

A mobile app that tracks app usage and converts unused apps into a shelf of taxidermy animals. If you open one again, it performs a dramatic flinch and starts a rehab streak.

## Features
- Track app usage through OS usage stats or a lightweight widget.
- Generate a taxidermy animal for each app that has been unused for a set time.
- Play a flinch animation and sound when a stuffed app is reopened.
- Track rehab streaks and award badges for keeping apps dormant.

## Stack
- React Native
- Expo
- SQLite
- Lottie

## Getting started
```
npm install && npx expo start, then run on iOS or Android with usage-tracking permissions enabled.
```
